# CB AI Solutions outreach

Agent: `.claude/agents/cb-outreach.md`

1. Fill in the TODOs in `business-profile.md` (or let the agent pull them from
   cbaisolutions.org and confirm them).
2. Add companies to `companies.csv` — or just paste them into chat.
3. Ask Claude: "Use the cb-outreach agent on these companies: ..."
4. Review the drafts it shows you (they are also in Gmail → Drafts) and say
   which to send.

Every email is sent from cbaisolutions.com@gmail.com only — the agent refuses
to run if Gmail is connected to a different account. History lives in `log.csv`.
